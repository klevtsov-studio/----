# Как обновлять и публиковать сайт

## Структура

```
index.html        главная страница: разметка, стили и вся логика в одном файле
stages.html       карта проекта — 30 стадий в 7 фазах
privacy.html      политика обработки персональных данных
worker.js         код Cloudflare Worker для приёма заявок в Telegram
models/           3D-модели кейсов и детали сцены первого экрана
img/              фотографии, чертежи, логотип, обложка для соцсетей
vendor/three/     локальная копия three.js — модели работают без внешних CDN
robots.txt        правила для поисковых роботов
sitemap.xml       карта сайта
```

Весь редактируемый текст лежит в объекте `SITE` в начале скрипта внутри `index.html`.

## Публикация через GitHub Pages

Подробная пошаговая инструкция с картинками кнопок и разбором ошибок — в файле `GITHUB.md`. Ниже краткая версия.

1. Создайте репозиторий на GitHub, например `klevtsov-studio`.
2. Загрузите содержимое этой папки в корень репозитория.
3. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)`.
4. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
5. Свой домен подключается там же: Settings → Pages → Custom domain.

Адрес в файлах сайта уже заменён. Если когда-нибудь смените домен, заменить нужно `https://klevtsov-engineering.ru`:
- в `index.html` — поле `SITE.url` и мета-теги canonical / Open Graph;
- в `robots.txt` и `sitemap.xml`;
- в воркере на Cloudflare — поле `origin` в блоке `CONFIG`.

## Правка контента

Открыть `index.html` в любом редакторе, найти `const SITE = {` и править значения.
Изменения видны сразу после сохранения и обновления страницы.

Локальный просмотр: в папке сайта выполнить `python3 -m http.server 8000`
и открыть `http://localhost:8000`. Без сервера 3D-модели не загрузятся —
браузер запрещает странице с диска читать соседние файлы.
