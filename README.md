# Инженерная студия Дмитрия Клевцова — сайт

Статический сайт, без сборки и зависимостей от внешних CDN.
Загружается на любой хостинг как есть — всей папкой.

```
index.html                  главная: разметка, стили, логика
stages.html                 карта проекта: 30 стадий в 7 фазах + компетенции
privacy.html                политика обработки персональных данных
models/table-3700.glb       3D-модель поворотного стола (2,6 МБ)
vendor/three/               локальная копия three.js (модель работает без интернета)
img/cases/<кейс>/           сюда фото: prod.jpg (производство), final.jpg (изделие)
img/founder/dmitry.jpg      портрет, вертикальный кадр 4:5
```

## Посмотреть локально

Проще всего — открыть двойным кликом файл **«САЙТ-открыть-двойным-кликом.html»**:
это та же страница, но с моделью и библиотеками, вшитыми внутрь файла.
Работает без интернета и без сервера. Файл только для просмотра — на хостинг
заливается папка целиком, а не он.

Двойной клик по обычному `index.html` покажет сайт, но **без 3D-модели**: браузер
запрещает странице, открытой с диска, читать соседние файлы. Если нужно проверить
именно рабочую версию — запустите в папке сайта локальный сервер:

```
python3 -m http.server 8000
```

и откройте `http://localhost:8000`. Локальный сервер — это программа, которая
раздаёт файлы из папки по адресу http://localhost; интернет и хостинг для этого
не нужны. На реальном хостинге всё работает сразу, без этих шагов.

## Что сделано с моделью стола

Исходный файл — 70 МБ, 1,58 млн треугольников, 831 меш: для сайта неподъёмно.
После обработки — **2,6 МБ и 393 тыс. треугольников** при той же геометрии:

- повторяющиеся детали (крепёж, ребра, пластины) сведены к общим мешам — 831 → 105;
- координаты и нормали квантованы, буферы сжаты meshopt;
- убрана камера из сборки и служебные узлы;
- **сняты все децимальные обозначения**: имена узлов и материалов вычищены,
  в файле не осталось ни «Т.0029», ни названий деталей. Остались нейтральные
  «Планшайба», «Рама», «Мотор-редуктор», «Крепёж» — они нужны для разнесения.

Имя файла тоже изменено: исходное `Т_0029_СБ-Стол_вертикально-поворотный_3700_мм.glb`
содержало обозначение и было бы видно в адресной строке.

**Проверьте перед публикацией**, вправе ли вы показывать эту сборку публично:
на сайте она крутится целиком и её можно рассмотреть с любой стороны.

## Как работает вкладка «3D-модель»

- модель грузится, только когда посетитель доходит до кейса (на мобильных — по кнопке);
- вращение мышью и пальцем, масштаб — кнопками, колесо остаётся у страницы,
  чтобы прокрутка не залипала;
- **ползунок «Собрано → Разнесено» разносит настоящую сборку по узлам**:
  планшайба вверх, рама вниз, привод и крепёж — наружу;
- если файл недоступен, просмотрщик молча показывает векторную схему.

## Добавить модель к другому кейсу

Экспортируйте GLB и укажите путь в `SITE.cases.items[].media.glb` —
вкладка «3D-модель» появится сама. Файлы тяжелее ~5 МБ пришлите мне: сожму так же.
Сейчас модель есть только у кейса 02.

## Страница стадий (stages.html)

Полная карта проекта из вашей методологии: 7 фаз, 30 стадий, ворота согласования
и блок компетенций. Каждая стадия помечена по исполнителю — студия, партнёр,
договорная точка или «только для крупных проектов». Данные в объекте `STAGES`
внутри файла: тексты, типы стадий и состав фаз меняются там.

Ссылка на страницу стоит в блоке «Процесс» на главной.

## Калькулятор оценки

Блок «Цены» считает по формуле, откалиброванной на четырёх реальных проектах студии:

```
часы = 0,85 × детали × k(вид работ) × k(новизна) × (1 + допработы)
цена = max(детали × 800 × k(вид), часы × 1200 ₽/ч) × срочность,
       но не ниже минимального чека 30 000 ₽
```

Проверка на факте: стол Ø2000 — расчёт 93 ч против 96 фактических,
навес КМД — 79 против 73, ПЗУ — 79 против 80, стол Ø1500 — 25 против 25.

Все ставки и коэффициенты — в `SITE.calc`: `perPart` (₽ за деталь),
`rate` (минимальная ставка ₽/ч), `hoursPerPart`, `minPrice`, `spread` (границы диапазона, сейчас −25% / +25%),
плюс списки видов работ, размеров, новизны и допработ. Меняются без правки логики.

Если задача выходит на минимальный чек, вместо диапазона показывается «от 30 000 ₽».
Ставка 1200 ₽/ч — целевая (фактическая средняя по четырём проектам была 1004 ₽/ч):
поменяете `rate` — пересчитается весь калькулятор.

Кнопка «Перенести в заявку» собирает из ответов черновик ТЗ и подставляет его
в форму внизу страницы — заявка приходит структурированной, а не «сколько стоит спроектировать?».

## Приём заявок в Telegram (worker.js)

Файл `worker.js` — код Cloudflare Worker, который принимает форму и пересылает
её вам в Telegram: текст заявки сообщением, приложенные файлы — документами.
Токен бота хранится на стороне Cloudflare и в браузер не попадает.

Порядок настройки:

1. **Бот.** В Telegram напишите @BotFather → `/newbot` → имя → username
   (должен заканчиваться на `bot`). В ответ придёт токен вида `7123456789:AAF…`.
2. **Свой chat id.** Напишите @userinfobot — он ответит числом. Затем обязательно
   напишите `/start` своему боту, иначе он не сможет вам писать.
3. **Worker.** Зайдите на dash.cloudflare.com → Compute (Workers) → Create →
   Start from Hello World → Deploy. Затем Edit code: удалите содержимое,
   вставьте `worker.js`, снова Deploy.
4. **Значения.** Два способа, любой рабочий:
   а) впишите токен и chat id прямо в блок `CONFIG` в начале `worker.js`
      (это код, а не комментарий — значения идут в кавычках), затем Deploy;
   б) либо Settings → Variables and Secrets: `BOT_TOKEN` (Secret),
      `CHAT_ID` (Secret), `ALLOWED_ORIGIN` (Text), затем Deploy.
   Переменные, если заданы, имеют приоритет над `CONFIG`.
   **Проверка:** откройте адрес воркера в браузере — страница покажет,
   заданы ли значения и виден ли бот.
5. **Сайт.** Скопируйте адрес воркера (`https://…workers.dev`) и вставьте
   в `SITE.form.endpoint` вместо `null`.
6. **Проверка.** Отправьте заявку с сайта — сообщение должно прийти в Telegram
   за пару секунд.

Ограничения: до 5 файлов, до 10 МБ каждый (правится в `SITE.form`).
Скрытое поле `website` в форме — ловушка для спам-ботов, люди его не видят.
Бесплатного тарифа Cloudflare (100 000 запросов в сутки) хватает с большим запасом.

## Где менять контент

Всё в объекте `SITE` в начале скрипта — тексты, кейсы, услуги, команда, контакты.

| Что | Где |
|---|---|
| Telegram, телефон, почта | `SITE.contacts` — **заглушки, заменить** |
| Приём заявок | `SITE.form.endpoint` — пока форма открывает почтовый клиент |
| Первый экран | `SITE.hero` |
| Кейсы, цифры, пути к фото и моделям | `SITE.cases.items` |
| Reverse engineering, процесс, команда, сегменты | `SITE.reverse`, `SITE.process`, `SITE.team`, `SITE.segments` |

Фото подставляются автоматически: как только файл появится по указанному пути,
он заменит заглушку.

## Оформление

Цвета — CSS-переменные в `:root`: `--hot` (оранжевый: металл, сварка, производство),
`--cold` (голубой: скан, данные, цифровая модель), графитовые фоны.
