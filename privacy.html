2. Какие данные собираются

Через форму на сайте оператор получает данные, которые вы вводите добровольно:

  • имя;
  • название компании — если указано;

Дополнительно при посещении сайта автоматически собираются обезличенные технические данные: IP-адрес, тип браузера и устройства, источник перехода, действия на страницах. Эти данные не позволяют идентифицировать вас лично.

Оператор не собирает специальные категории данных (о здоровье, убеждениях, национальности) и биометрические данные. Не запрашивайте и не присылайте такие сведения через форму.

Оператор не использует ваши данные для рекламных рассылок и не передаёт их третьим лицам для маркетинга. Данные не продаются и не публикуются.

Данные хранятся, пока это необходимо для целей обработки: в течение переписки по задаче, срока действия договора и трёх лет после его завершения — для подтверждения выполненных обязательств. Если сотрудничество не состоялось, данные удаляются в течение года с момента последнего обращения либо раньше — по вашему требованию.
